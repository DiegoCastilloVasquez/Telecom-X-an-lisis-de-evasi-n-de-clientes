# Telecom-X-an-lisis-de-evasi-n-de-clientes
Este proyecto forma parte de un desafío de análisis de datos para Telecom X. El objetivo es analizar una base de datos de clientes, aplicar técnicas de ETL (Extracción, Transformación y Carga) y realizar un Análisis Exploratorio de Datos (EDA) para descubrir los principales factores que motivan a los clientes a cancelar sus servicios.
